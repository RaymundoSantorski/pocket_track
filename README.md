# Pocket Track

Application made with flutter, meant to take care of self finances.

## About

This project is meant to be totally free with some ads, launched in the Play Store and App Store.

- Create, update and delete transactions.
- Transactions can be incomes or expenses.
- App calculates your current balance, positive, negative or zero.

## Coming up

There are some funcionalities I want to add in the future.

- Create and use Account types, like bank, digital wallets, cash, debt, credit, etc.
- Statistic about your transactions.
- History 
- Notifications
